# Cookster za Windows (Electron)

Igrica u svom prozoru. Gradi se na GitHub-u:
1. Otvori **Actions → Windows build → Run workflow**.
2. Kad se završi, sa dna stranice preuzmi **Cookster-Windows** (zip sa `Cookster Setup 1.0.0.exe` i `Cookster 1.0.0.exe`).
3. `Setup` instalira igricu; drugi fajl radi bez instalacije.

Na računaru sa Node-om: `cd desktop && npm install && npm start` (proba), `npm run dist` (pravi .exe na Windowsu).
Tasteri: F11 ceo ekran, F12 alati za razvoj, F5 osveži.
